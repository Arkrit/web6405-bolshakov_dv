## Реализованные требования
- используются только HTML5 и CSS3
- три HTML-страницы
- блочные и строчные элементы
- внутренние и межстраничные ссылки
- SVG-картинка
- таблица
- внешний файл `style.css`
- элементные, классовые и псевдоклассовые CSS-селекторы
- цвета и разные варианты выравнивания ячеек таблицы
